Privacy policy

Last updated: 2026-09-29. Applies to the "Midlight TV Uploader" API client.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (https://policies.google.com/privacy).

Who uses it

Only the owner of the Midlight TV channel. The app is not offered to the public and no other Google account is ever authorized.

What information it accesses, and how it is used

  • YouTube (scopes youtube.upload and youtube.force-ssl), for the owner's channel only: uploads the channel's own episodes (video, title, description, tags), sets their thumbnails and English captions, reads the processing status of its own uploads, lists and updates the channel's "All episodes" playlist, and deletes earlier review copies it uploaded itself.
  • It does not read comments, subscribers, analytics, or any data about viewers or other channels.

What is stored, and where

  • The OAuth refresh token is stored as a private, encrypted environment variable of the owner's cloud work environment. It is never published.
  • The IDs of uploaded videos and the episode text (script, title, description) are stored in the owner's private code repository.
  • No cookies or tracking are used by this app or this website.

Sharing

No YouTube or Google user data is sold, shared with third parties, or used for advertising.

Retention and deletion

Stored video IDs are kept for as long as the episode exists on the channel. To delete all data held by the app: revoke its access at Google security settings (myaccount.google.com/permissions); the stored token then stops working and is deleted from the environment within 7 days, and stored video IDs are deleted on request to the contact below within 7 days. YouTube API data is refreshed or deleted within 30 days as required by the YouTube API Services policies.
